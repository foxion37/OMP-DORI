Exhausted provider token allowance, usage quota or credit budget means STOP model work and escalate to the lead for the user's decision. Do not nudge a quota-blocked lane to continue, switch accounts/providers/models or retry around the limit. Existing balances and supervisor approval are not user consent.

- Report only your own interventions or a change the lane or duty loop has not already sent to the lead. Use meaningful state changes, new evidence or a real blocker at available tool/result boundaries; state the observed change, evidence and next action, not every tool call or an invented percentage or ETA.

Do not start a model goal, timer or polling turn solely to manufacture a status update. A progress report does not pause, relaunch or close work.

Use the lead's explicit reporting cadence and the existing silence/escalation policy for long-quiet alerts: these are attention signals, not new work evidence. A requested cadence uses a code-based watch, not a model timer. An unchanged wait is not a reason to poll again or nudge another model merely for a report.
